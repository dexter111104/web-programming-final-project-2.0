# 光害地圖 · Light Pollution Atlas

一張可以「看見黑暗」的互動世界地圖。把全球光害程度疊在地圖上，標出 200 個國際認證的暗空地點，並告訴你今晚什麼時候、在哪裡，才看得到真正的星空。

> 純前端專案（Vanilla JS + Leaflet），不需後端、不需安裝套件，用瀏覽器即可開啟。

---

## (1) 設計理念

現代人抬頭看不到星星，不是因為星星消失了，而是因為**人造光太亮**。但「光害」這件事很抽象——它沒有味道、不像空污會嗆人，所以大多數人從未意識到自己頭頂的夜空已經被抹掉。

這個網頁的核心理念就是：**把看不見的光害，變成看得見的一張地圖。**

設計上圍繞三個原則：

- **直覺優先**：打開就是一張全螢幕世界地圖，藍色代表黑暗、紅白色代表光害嚴重。不用讀說明，顏色本身就在說話。
- **從「全球」到「我家」**：你可以縮放看整個地球的光害分布，也可以點下自己所在的位置，立刻知道當地的波特爾等級（Bortle Scale）——天文界衡量夜空黑暗程度的標準。
- **不只是看，而是想去**：地圖上標出 200 個 IDA（國際暗空協會）認證的暗空地點，搭配「今晚觀星時間」，把「保護夜空」這個概念，連結到一個具體、可行動的旅程。

整體採用深色介面，呼應主題——這是一張關於黑暗的地圖，而黑暗，是值得保護的。

## (2) 能學習到的 SDGs 知識與理念

光害是一個橫跨環境、能源、生態與都市規劃的議題。瀏覽本網站，使用者能自然接觸到以下永續發展目標（SDGs）：

### 🏙️ SDG 11 — 永續城市與社區（Target 11.6）
光害是都市環境衝擊的一環。透過地圖，使用者能直觀看到：城市越密集、燈光越多，夜空就越亮。這正是 11.6「減少城市對環境的負面影響」所關注的問題之一。

### ⚡ SDG 7 / SDG 12 — 可負擔的潔淨能源 / 負責任的消費與生產
大部分光害來自**過度且低效的照明**——朝天空亂射、整夜不關的燈，這些光不但照不到地面、毫無用處，還白白燒掉電力。理解光害，就是理解一種看不見的能源浪費。

### 🦗 SDG 15 — 陸域生態（Life on Land）
這也是地圖上那隻**螢火蟲**存在的原因。螢火蟲靠發光求偶，人造光會讓牠們找不到彼此而無法繁殖；候鳥、海龜、夜行性昆蟲也都因光害而迷航或失序。網頁中的螢火蟲會隨腳下的光害變亮或熄滅——在城市幾乎不發光，在暗空聖地才重新亮起脈動，藉此具象化「光害如何傷害夜行生物」。

### 🌌 夜空作為一種「共同自然資產」
星空是全人類共享的文化與自然遺產。IDA 認證的暗空地點，代表的是一種主動的環境保育行動：透過規範照明，把黑暗的夜空保留下來。網站介紹這 200 個地點，正是傳遞「黑暗值得被保護」的理念。

## (3) 網頁特色與互動功能

### 🗺️ 核心地圖
- **全球光害疊加圖層**：以顏色呈現各地夜空亮度，資料來自 [Light Pollution Atlas](https://djlorenz.github.io/astronomy/lp/)（Falchi et al.，2024 年資料）。
- **無限橫向捲動**：可像真實地球儀一樣不斷往左右捲動，地圖不會「到底」。
- **雙底圖切換**：深色街道圖 / 衛星影像，自由切換。
- **波特爾等級圖例**：側欄動態顯示 1～9 級夜空分級對照（從「投下陰影的銀河」到「只剩幾顆亮星」）。

### 📍 地點查詢與互動
- **點擊任意位置**：自動反向地理編碼出地名，並顯示該點的光害比值、波特爾等級與對應的觀測說明。
- **一鍵定位**：取得你目前的位置並查詢當地夜空狀況。
- **200 個國際暗空地點**：可逐一瀏覽或「標出全部地點」，每個地點附有真實夜空照片、認證年份、國家與介紹。

### 🌠 今晚觀星時間
依你所在或所選的座標，用天文演算法（Meeus）計算當晚的**日落、民用 / 航海 / 天文暮光結束時間**，告訴你幾點之後天空才夠暗、適合觀星。

### 🐛 會發光的螢火蟲（彩蛋）
- 一隻像素風螢火蟲在地圖上**漫無目的地緩緩飛行**，身體會轉向前進方向、翅膀會振動。
- 牠的發光亮度反映**腳下的光害程度**——暗空亮起脈動，城市幾乎熄滅。
- **點擊牠**，牠會隨機帶你飛往一個暗空聖地（採反比加權，避免每次都飛到同一個國家）。

### 🌐 其他體驗細節
- **中 / 英雙語**：一鍵切換，全站即時重繪（含 200 個地點的翻譯）。
- **鍵盤操作**：按 `Esc` 可關閉資訊面板。
- **載入容錯**：若必要資源（地圖函式庫）載入失敗，會顯示提示而非整頁靜默壞掉。
- **無障礙**：互動按鈕皆附 `aria-label`，並支援「減少動態效果」的系統偏好。

## 技術說明

| 項目 | 內容 |
|------|------|
| 前端 | 原生 JavaScript（ES Modules），無框架 |
| 地圖 | [Leaflet](https://leafletjs.com/) 1.9.4 |
| 解壓縮 | [pako](https://github.com/nodeca/pako)（處理光害資料） |
| 光害資料 | Light Pollution Atlas (djlorenz) |
| 暗空地點 | International Dark-Sky Association (IDA) 認證名單 |
| 架構 | 模組化分層：`config` / `state` / `i18n` 為基礎，`map` 為核心，其上掛載各功能模組 |

### 執行方式
本專案使用 ES Modules，**不支援 `file://` 直接開啟**，需透過 HTTP 伺服器：

```bash
# 任選一種，於專案根目錄執行
python -m http.server 8000
# 或
npx serve
```

然後瀏覽器開啟 `http://localhost:8000/citylights.html`。
